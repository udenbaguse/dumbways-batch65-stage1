## 🚀 Cara Menjalankan Proyek

1. **Clone Repositori**
   ```bash
   git clone https://github.com/username/dumbways-batch65-stage1.git
   ```
2. **Buka Project**
   Masuk ke direktori tugas yang ingin dilihat, misalnya:
   ```bash
   cd hari-ke-2
   ```
3. **Jalankan**
   Klik kanan pada file `index.html` dan pilih **Open with Live Server** atau cukup buka file tersebut langsung di browser favorit Anda.
